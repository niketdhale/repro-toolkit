# Code of Conduct

This project follows the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good intent, and keep discussion about the work.
Harassment and personal attacks are not tolerated.

## Reporting

To report unacceptable behavior, email the maintainer at niketdhale12@gmail.com.
Reports are kept confidential.
